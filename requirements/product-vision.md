# Product Vision

## Rkestr

Rkestr is an enterprise work-orchestration platform designed to help individuals, families, and work teams move from intention to execution.

The product goes beyond a basic todo list.

### Core loop

Capture → Classify → Prioritize → Plan → Execute → Delegate → Remind → Complete

### Primary capabilities

- Authentication and authorization
- Workspaces
- Work Items
- Categories and contexts
- Priority, importance, and urgency
- Eisenhower decision framework
- Soft and hard deadlines
- Planned start
- Reminders
- Delegation
- Subtasks
- Dependencies
- Work Sessions
- Notifications
- Search and saved views
- Productivity views
- Auditability
- Enterprise security
- Data retention
- Attachments
- Future calendar integrations
- Future analytics
- Future AI-assisted planning

## Product terminology

The primary domain entity is **Work Item**, not Todo.

A Work Item represents a meaningful unit of work that may be personal, family, or professional.

A **Subtask** is a meaningful unit of work within a Work Item.

A **Work Session** is a focused period of execution and is independent of subtasks.
