# Engineering Sprint 0 — Repository & Development Foundation

## Goal

Create the three-repository engineering foundation and establish local development for the backend and frontend.

## Repositories

1. `risa-rkestr-architecture`
2. `risa-rkestr-backend`
3. `risa-rkestr-frontend`

## Initial scope

Architecture:
- Repository structure
- Architecture documentation
- ADR structure
- Diagrams
- Sprint documentation

Backend:
- Spring Initializr
- Java 21+
- Spring Boot
- Maven
- PostgreSQL local development
- Migration framework
- Testing foundation
- CI foundation

Frontend:
- Next.js
- React
- TypeScript
- Testing foundation
- CI foundation
