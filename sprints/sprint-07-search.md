# Sprint 7 — Productivity & Search

## Frozen decisions

- PostgreSQL-backed search initially
- PostgreSQL remains authoritative
- OpenSearch is a future extraction option
- Composable filters
- Deterministic sorting
- Cursor pagination by default for high-volume lists
- Authorization enforced in search boundary
- Saved Views store query definitions, not snapshots
- System productivity views
- Eisenhower Matrix is derived
- Bulk operations respect domain rules and authorization
- Large bulk operations may become asynchronous
