# User Flow — Delegate Work Item

```text
Open Work Item
  |
Delegate
  |
Select workspace member
  |
Authorization
  |
Assignment / ownership rules
  |
Confirm
  |
Persist change
  |
Audit
  |
Emit event
  |
Async notification
```

Delegation does not automatically imply ownership transfer.

Created By, Owner, and Assignee remain distinct concepts.
